3. Seguridad

3. Security

El acceso de escritura a tus datos de suscripción está restringido por reglas de seguridad a nivel de fila (RLS); ningún cliente puede otorgarse acceso Pro directamente. Los eventos de pago se verifican con una firma criptográfica antes de procesarse.

Write access to your subscription data is restricted by row-level security (RLS) rules; no client can grant itself Pro access directly. Payment events are verified with a cryptographic signature before being processed.

4. Cookies

We use cookies/local storage to remember your language preference and sign-in session, plus those set by the Paddle checkout during payment.
